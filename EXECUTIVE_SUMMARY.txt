## 🔄 How It Works

```
Request arrives
    ↓
Gateway routes to service
    ↓
Service lookup fails
    ↓
Gateway throws exception
    ↓
GlobalExceptionHandler catches it
    ↓
Exception is classified (503/404/400/500)
    ↓
JSON response is built
    ↓
Error is logged
    ↓
Response sent to client
```
