================================================================================
                            COMMON HTTP STATUSES
================================================================================

503 Service Unavailable
  → Microservice is down or not registered with Eureka
  → Message: "The requested microservice is currently unavailable..."
  → Action: Start the service or check Eureka registration

404 Not Found
  → Endpoint doesn't exist
  → Message: "The requested resource was not found"
  → Action: Check the endpoint path

400 Bad Request
  → Invalid request parameters or malformed JSON
  → Message: "Invalid request parameters"
  → Action: Verify request body and headers

500 Internal Server Error
  → Unexpected server-side error
  → Message: "An unexpected error occurred..."
  → Action: Check service logs

================================================================================
                          STARTUP SEQUENCE
================================================================================

1. Start Eureka Server (8761)
2. Start Auth Service (8081)
3. Start User Service (8082)
4. Start Startup Service (8083)
5. Start API Gateway (8080)

All services should show as UP in Eureka after ~30-60 seconds.

================================================================================
                        TROUBLESHOOTING CHECKLIST
================================================================================

If you see "Service Unavailable (503)":
  ✓ Check if service is running: curl http://localhost:8083/actuator/health
  ✓ Check Eureka: curl http://localhost:8761/eureka/apps
  ✓ Verify port is not in use: netstat -ano | findstr :8083
  ✓ Check service logs for errors
  ✓ Restart the service

If you see "Not Found (404)":
  ✓ Verify endpoint path is correct
  ✓ Check route configuration in ApiGatewayApplication.java
  ✓ Ensure service is responding on expected path

If you see raw stack traces (something is wrong):
  ✓ Rebuild Gateway: mvn clean package
  ✓ Verify GlobalExceptionHandler is in classpath
  ✓ Clear target directory: rm -r target
  ✓ Restart Gateway
  ✓ Check that no other exception handlers are conflicting

If all requests return 500:
  ✓ Check if Eureka is running
  ✓ Check if databases are accessible
  ✓ Verify network connectivity
  ✓ Check service logs

================================================================================
                          WORKING WITH ERRORS
================================================================================

For API Consumers:
  • Check the 'status' field for HTTP status code
  • Use 'message' field for user-facing messages
  • Use 'path' field for debugging which endpoint failed
  • Implement retry logic for 503 errors with exponential backoff

For Developers:
  • Check gateway logs for error details
  • Use 'timestamp' field to find related logs
  • Look for [GATEWAY ERROR] in console output
  • Monitor error rates by service
